# Screen Keeper

## Installation

1. Install the APK
2. Run the app and click "Grant Permission", click on the "Screen Keeper" item in the list
3. The toggle will be disabled, but click the toggle and a popup will appear saying "App was denied access"
4. Go to the App Info page (either click and hold the "Screen Keeper" app icon, or go to Settings -> Apps -> Screen Keeper), click the 3 dots in the top right corner, and click  "Allow restricted settings"
5. Scroll down to the "Display over other apps" option, the toggle show now be enabled; enable it
6. Go back to the app, now you should be able to click "Toggle Service"
